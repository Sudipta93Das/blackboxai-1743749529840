## TRLM Letter Tracking & Analytics Dashboard
This repository includes the implementation specification and database schema updates for the Tripura Rural Livelihood Mission (TRLM) Letter Tracking & Analytics Dashboard.

### What's Included
- Detailed implementation spec with district-wise reply dates, district-wise statuses, and district-level alert system.
- Database schema and seed placeholders.

### Files
- `docs/trlm-dashboard-spec.md` — Implementation spec and requirements.
- `database/schema.sql` — Database schema including district-level reply tracking.
- `database/seed.sql` — Seed for the admin user (replace the password hash with bcrypt).
